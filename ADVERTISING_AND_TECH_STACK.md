## 2. Яка рекламна система принесе найбільший прибуток (Revenue)?

Для продажу деревних пелет у **Дніпропетровській області** та по Україні ми проаналізували всі ключові рекламні платформи:

### 🥇 1 місце: Google Search Ads (Пошукова реклама Google) — Найвищий ROI
* **Чому це №1**: Покупець у Google вже шукає паливо прямо зараз (почався сезон, закінчився запас на складі, запускається зерносушарка). Це «гарячий» комерційний попит.
* **Цільова аудиторія**: Головні енергетики, директори підприємств, власники агрофірм, комунальні котельні Дніпра, Кривого Рогу, Нікополя, Кам'янського.
* **Рекомендовані кампанії**:
  * Пошукові запити: `пелети оптом дніпро`, `купити деревні пелети нікополь`, `пелети біг бег ціна`, `пелети від виробника з пдв`.
  * Очікувана вартість ліда (CPA): ~\$2.5 – \$5.
  * Очікуваний чек угоди: від 60 000 до 120 000 грн за партію 15–22 т.

### 🥈 2 місце: Meta Ads (Facebook & Instagram) — Найкраще для масштабування та впізнаваності
* **Чому це працює**: В Україні власники агробізнесу, фермери, керівники виробництв та приватних тепличних господарств активно користуються Facebook та Instagram.
* **Формати, що приносять дохід**:
  * **Відео-оголошення (Reels / Feed)**: Жива зйомка відвантаження біг-бегів на складі в Нікополі, чисте горіння гранули, демонстрація мінімальної зольності.
  * **Карусель переваг**: *«Прямо від заводу в Нікополі • Опт від 15 тонн • Безготівка з ПДВ • Доставка по Дніпропетровській області за 24–48 год»*.
  * **Кампанія з лід-формами (Lead Generation)** або спрямування на сайт у розроблений калькулятор.
* **Піксель вже інтегровано**: У файлі `assets/js/analytics-config.js` просто вкажіть ваш `META_PIXEL_ID`, і сайт почне передавати всі події (`PageView`, `Contact`, `CustomizeProduct`, `Lead`).

### 🥉 3 місце: Регіональні Viber та Telegram канали Дніпропетровщини
* Пряме розміщення оголошень в аграрних та промислових бізнес-чатах Нікопольського району, Дніпра та Кривого Рогу. Дає швидкі заявки без бюджету на рекламу.

## 3. Як перевірити, чи працює відстеження Google Ads?

Щоб переконатися на 100%, що ваші конверсії та теги Google Ads налаштовані правильно і фіксують кожну заявку, виконайте наступні кроки:

### Крок 1. Пропишіть ваші ID у конфігурації
Відкрийте `assets/js/analytics-config.js` та вставте ваші дані з кабінету Google Ads:
```javascript
GOOGLE_ADS_CONVERSION_ID: 'AW-123456789',   // Ваш ID тегу Google Ads
GOOGLE_ADS_CONVERSION_LABEL: 'AbCdEfGhIjKl'  // Ярлик дії-конверсії
```

### Крок 2. Миттєвий тест у браузері без запуску платної реклами
1. Відкрийте ваш сайт у браузері Chrome чи Edge.
2. Натисніть клавішу `F12` і перейдіть на вкладку **Console** (Консоль).
3. Введіть команду:
   ```javascript
   window.testAdConversion()
   ```
4. Натисніть `Enter`. Система виведе повну діагностику:
   - Чи підключено скрипти Google (`gtag`) та Meta (`fbq`).
   - Які збережені UTM-мітки активні.
   - Миттєво відправить тестову подію конверсії `Lead`.

### Крок 3. Офіційна перевірка через Google Tag Assistant
1. Перейдіть на офіційний сервіс Google: [tagassistant.google.com](https://tagassistant.google.com).
2. Натисніть **Add domain** і введіть адресу вашого сайту (наприклад, `https://ukrpellet.ua` або URL з Vercel).
3. Відкриється нове вікно вашого сайту з бейджем *Tag Assistant Connected*.
4. Надішліть заявку через форму або натисніть кнопку розрахунку калькулятора.
5. У вікні Tag Assistant ви побачите зелену галочку:
   - `Google Ads Conversion Tracking — Fired 1 time` з переліком параметрів (сума, валюта `UAH`).

### Крок 4. Перевірка статусу в рекламному кабінеті Google Ads
- Перейдіть у розділ **Цілі** (Goals) -> **Конверсії** (Conversions) -> **Зведення** (Summary).
- Знайдіть вашу дію-конверсію (наприклад, *«Відправка форми заявки на пелети»*):
  - Статус **«Активно»** або **«Запис конверсій»** (Recording conversions) означає, що система працює бездоганно.

## 4. Чи можна підключити Vercel та Supabase всередині Antigravity?

**ТАК, на 100%!** Ви можете повністю керувати і Vercel, і Supabase прямо всередині Antigravity. Ось як це працює:

### 1. Через вбудовану командну стрічку (CLI) прямо в нашому чаті:
Ви можете просто сказати мені: *«Розгорни сайт на Vercel»* або *«Застосуй міграцію в Supabase»*. 
- **Для Vercel**: Ми використовуємо команду `npx vercel`:
  - `npx vercel login` — одноразова авторизація.
  - `npx vercel --prod` — миттєве публічне оновлення сайту з генерацією безкоштовного SSL.
  - `npx vercel env add` — додавання секретних ключів (токенів Telegram, бази тощо).
- **Для Supabase**: Ми використовуємо команду `npx supabase`:
  - `npx supabase login`
  - `npx supabase db push` — автоматичне накачування таблиць і політик безпеки на хмарну базу.

### 2. Через протокол MCP (Model Context Protocol):
Antigravity підтримує MCP-сервери (як і зазначено в конфігурації системи). Ви можете додати офіційні сервери:
- **Supabase MCP Server**: дозволяє Antigravity напряму виконувати SQL-запити, дивитися нові заявки, створювати бекапи та додавати колонки без відкриття браузера.
- **Vercel MCP Server**: дозволяє Antigravity інспектувати логи збірки, відстежувати помилки серверних функцій `api/lead.js` та перевіряти домени.

### 3. Через змінні середовища `.env`:
Усі ключі (`SUPABASE_URL`, `SUPABASE_ANON_KEY`, `TELEGRAM_BOT_TOKEN`) можна зберегти у файлі `.env.local` у корені проєкту — Antigravity та Vercel автоматично використовують їх для серверних функцій.

## 5. Впровадження стандарту Claude-SEO (від AgriciDaniel/claude-seo)

Відповідно до репозиторію **Claude-SEO**, ми реалізували повний комплекс вимог пошукової оптимізації та штучного інтелекту (GEO):

1. **Мікророзмітка Schema.org (JSON-LD)**:
   - `LocalBusiness` / `WholesaleStore` на головній сторінці: фіксує підприємство як реального фізичного виробника у м. Нікополь із точними GPS-координатами (`47.5675, 34.3948`), робочими годинами, контактами (`+380994937366`) та зоною обслуговування (Дніпропетровська область, Україна, Польща).
   - `Product` та `AggregateOffer` на лендінгу пелет: структурує цінові діапазони, мінімальну оптову партію (15 тонн) та наявність товару.
2. **Карта сайту Sitemap.xml ([sitemap.xml](file:///c:/Users/xaker/OneDrive/Документы/IA-TEMS/sitemap.xml))**:
   - Повноцінна XML-карта з підтримкою тегів `xhtml:link rel="alternate"` для української та англійської версій.
3. **Файл директив пошукових роботів ([robots.txt](file:///c:/Users/xaker/OneDrive/Документы/IA-TEMS/robots.txt))**:
   - Надає повний доступ пошуковим роботам Googlebot, Bingbot та вказує шлях до карти сайту.
4. **Канонічні посилання та Hreflang**:
   - Захист від дублів сторінок (`rel="canonical"`).
   - Точна географічна локалізація за міжнародним стандартом ISO 639-1 (`hreflang="uk"`, `hreflang="en"`, `hreflang="x-default"`).
