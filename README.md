# UkrEcoPelleta & ТОВ «УКРЕКОПЕЛЕТА» — Веб-сайт компанії та Регіональний Лендінг Продажу Пелет

Сучасний, швидкий, двомовний (українська та англійська) веб-проєкт для підприємства **ТОВ «УКРЕКОПЕЛЕТА»** та торговельного бренду **UkrEcoPelleta**.

Сайт розроблено з урахуванням екологічної стилістики (зелені, чисті білі та теплі деревні тони), оптимізовано під регіональну інтернет-рекламу (Google Ads, Meta Ads) у **Дніпропетровській області** з виробничою базою у **м. Нікополь**.

---

## 🌲 Основні характеристики проєкту

1. **Два пов'язані напрямки**:
   - `index.html` — **Головний корпоративний портал компанії (UkrEcoPelleta / ТОВ «УКРЕКОПЕЛЕТА»)**:
     - Огляд підприємства: що компанія має (завод у Нікополі, обладнання, склади 3000 м², лабораторія контролю якості, логістика).
     - Чим компанія займається (промислова переробка деревини: сосна, акація, берест, виготовлення біопалива, партнерство, експорт до Польщі/ЄС).
   - `pellets.html` — **Цільовий регіональний лендінг продажу (UkrEcoPelleta)**:
     - Оптимізований під конверсію рекламного трафіку з Дніпра та області.
     - Чітка умова: **мінімальна партія для доставки по області — 15 біг-бегів (~15 тонн)**.
     - Самовивіз у м. Нікополь зі складу або локальні умови.
     - Інтерактивний **онлайн-калькулятор тонн, біг-бегів та енерговіддачі (МВт·год)**.
     - Технічні специфікації (діаметр 6/8 мм, зольність < 0.6%, вологість < 8%, плейсхолдер для породи деревини).
     - Фасування (Біг-Беги 1000 кг та мішки 15 кг).
     - Блок швидкого зв'язку у месенджерах: Telegram, Viber, телефонний дзвінок.
     - Модальне вікно швидкого запиту комерційної пропозиції.
     - Блок частих запитань (FAQ).

2. **Двомовність (UA / EN)**:
   - Повна локалізація інтерфейсу та всіх текстових блоків.
   - Миттєве перемикання мови без перезавантаження сторінки з запам'ятовуванням у `localStorage`.

3. **Кольорова гама та стиль**:
   - Глибокий лісовий зелений (`#1e5631`, `#2d7f48`)
   - Свіжий екологічний акцент (`#22c55e`, `#86efac`)
   - Теплий натуральний колір деревини / бурштиновий (`#966138`, `#d8a47f`, `#f6ede3`)
   - Чистий білий та світлий еко-фон (`#ffffff`, `#fcfbf9`)
   - Чіткі адаптивні картки, зручні кнопки (розмір від 48px для комфортного натискання на смартфонах).

4. **Високоякісні графічні матеріали**:
   - Всі зображення вже додані у високій роздільній здатності в папку `assets/images/`:
     - `hero-pellets.jpg` (макро-фото золотистих деревних гранул)
     - `big-bags-warehouse.jpg` (сучасний склад з рядами біг-бегів по 1 тонні)
     - `production-plant.jpg` (сучасний біоенергетичний виробничий комплекс у Нікополі)

## 🚀 Як відкрити та запустити сайт

### Варіант 1: Без жодних встановлень (миттєво)
Просто двічі клацніть на файл `index.html` або `pellets.html`, щоб відкрити його в улюбленому браузері (Chrome, Edge, Safari тощо).

### Варіант 2: Через Node.js / npm
У терміналі в цій папці виконайте:
```bash
npm start
```
Сервер запуститься за адресою `http://localhost:3000`.
